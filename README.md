# MyZman ל-Mac

[![Build & Release](https://github.com/zevisvei/MyZmanMac/actions/workflows/release.yml/badge.svg)](https://github.com/zevisvei/MyZmanMac/actions/workflows/release.yml)

אפליקציית שורת תפריטים נייטיבית (SwiftUI) לזמני היום ולתאריך העברי. מבוססת על [MyZman](https://github.com/NykUser/MyZman) (רשימת 166 הזמנים, המיקומים וברירות המחדל), עם רעיונות מ-[ItimHebrewCalendar](https://github.com/abaye123/ItimHebrewCalendar) (לוח חודשי, ממיר, מעבר תאריך בשקיעה). החישובים נעשים ב-[KosherSwift](https://github.com/Elyahu41/KosherSwift), פורט של KosherJava.

## מה יש

- **שורת התפריטים** מציגה כל הזמן, גם כשהחלון סגור, את התאריך העברי ואת הזמן הבא עם ספירה לאחור. אפשר גם להציג זמן קבוע לבחירתכם. מה מוצג נקבע בהגדרות.
- **החלונית** כוללת:
  - תאריך עברי ולועזי, פרשה, חגים, ספירת העומר ודף יומי.
  - רשימת זמנים שבה זמן שעבר צבוע באדום, זמן שעוד לא הגיע בכחול, והזמן הבא מודגש.
  - לוח חודשי עברי עם דילוג לחודש, לשנה, לתאריך או למועד.
  - ממיר תאריכים לועזי↔עברי.
- **הזמנים:** 166 חישובים מ-MyZman. אפשר להוסיף, להסיר, לשנות שם ולגרור לשינוי הסדר.
- **מיקומים:** 236 מיקומים מ-MyZman, מיקומים מותאמים אישית, ואיתור המיקום הנוכחי.
- **יומן (בשני הכיוונים):**
  - כתיבה של התאריך העברי, החגים והזמנים ללוח שבוחרים. זה יכול להיות גם לוח Google שמחובר למק. האפליקציה מוחקת ומעדכנת רק אירועים שהיא עצמה יצרה.
  - הצגה של האירועים שלכם בלשונית „לוח”, ונקודה כחולה בלוח החודשי בימים שיש בהם אירועים.
  - הוספת אירוע, כולל אירוע שחוזר לפי תאריך עברי (יארצייט, יום הולדת עברי).
  - ייצוא לקובץ ‎.ics.
- **ארבעה ווידג'טים** לשולחן העבודה ולמרכז העדכונים: הזמן הבא עם ספירה לאחור, זמני היום, תאריך עברי (דף לוח), זמני שבת.
- **תזכורות** לפי זמן (למשל 10 דקות לפני השקיעה) או בשעה קבועה. אפשר לקבוע שיחזרו כל יום, בימים מסוימים בשבוע, או פעם אחת בתאריך מסוים.
- **מראה:** בהיר, כהה או לפי הגדרת המערכת.
- **ייצוא ל-CSV** (Excel).
- **הפעלה עם הכניסה למחשב:** מופעלת אוטומטית בהרצה הראשונה, ואפשר לכבות בהגדרות ← כללי.

## הורדה

הגרסה האחרונה נמצאת ב-[Releases](https://github.com/zevisvei/MyZmanMac/releases/latest). הורידו את `MyZman.dmg` וגררו את MyZman ל-Applications. נדרש macOS 14 ומעלה.

בפתיחה הראשונה macOS מזהיר ש„המפתח לא מזוהה”. לחצו על האפליקציה לחיצה ימנית ← „פתח”. הווידג'טים עובדים מיד. פרטים בפרק [חתימה, ווידג'טים ואזהרת „מפתח לא מזוהה”](#חתימה-ווידגטים-ואזהרת-מפתח-לא-מזוהה) למטה.

## בנייה מהקוד

צריך רק את Command Line Tools, בלי Xcode.

```sh
scripts/build_app.sh            # בונה את build/MyZman.app
scripts/build_app.sh --install  # מתקין ל-/Applications ומפעיל
```

## חתימה, ווידג'טים ואזהרת „מפתח לא מזוהה”

### ווידג'טים

macOS מציג בגלריית הווידג'טים רק ווידג'טים של אפליקציה שחתומה **בתעודה**. חתימה מקומית בלבד (ad-hoc) לא מספיקה. התעודה לא חייבת להיות של Apple: גם תעודה עצמית (self-signed) עובדת, והמשתמשים לא צריכים לסמן אותה כמהימנה.

- **מי שמוריד גרסה מ-Releases:** כל גרסה נחתמת ב-CI בתעודה העצמית של הפרויקט, „MyZman Release Signing”. הווידג'טים עובדים מיד, בלי Xcode, בלי Apple ID ובלי שום פעולה. להוספה: לחיצה ימנית על שולחן העבודה ← „עריכת ווידג'טים” ← מחפשים „זמנים”.
- **מי שבונה מהקוד:** `scripts/build_app.sh` חותם אוטומטית בתעודה אם יש כזו ב-Keychain. אם אין, אחרי ההתקנה לוחצים בהגדרות ← כללי ← **„הפעלת ווידג'טים”**, או מריצים `scripts/enable-widget.sh`. הסקריפט יוצר תעודה מקומית בפעם הראשונה, חותם מחדש את האפליקציה המותקנת ופותח אותה. אפשר לחתום אפליקציה אחרי הקימפול, בלי לבנות אותה מחדש.

אחרי חתימה מחדש בתעודה אחרת, macOS עשוי לבקש לאשר שוב גישה ליומן ולמיקום, כי ההרשאות קשורות לזהות החתימה. לכן כל הגרסאות נחתמות באותה תעודה.

### אזהרת „מפתח לא מזוהה”

התעודה העצמית לא מאומתת אצל Apple (notarization דורש חשבון מפתח בתשלום). לכן בפתיחה הראשונה macOS מזהיר ש„המפתח לא מזוהה”. הפתרון: לחיצה ימנית על האפליקציה ← „פתח”, או:

```sh
xattr -dr com.apple.quarantine /Applications/MyZman.app
```

### למתחזק: הגדרת תעודת הגרסאות (פעם אחת)

```sh
scripts/setup-release-signing.sh
```

הסקריפט עושה שלושה דברים:
1. יוצר את התעודה „MyZman Release Signing”.
2. מייבא אותה ל-Keychain, כדי שבנייה מקומית תיחתם בה.
3. מעלה אותה לסודות של המאגר ב-GitHub (`SIGNING_CERT_P12_BASE64`, `SIGNING_CERT_P12_PASSWORD`).

התיקייה `certs/` נשארת מחוץ ל-git. שמרו לה גיבוי. כשהסודות לא מוגדרים, ה-CI בונה בחתימה מקומית ומציג אזהרה, ובגרסאות כאלה הווידג'טים לא יופיעו.

### למה בהתחלה הווידג'טים לא הופיעו (לעניין טכני)

שתי סיבות:
1. **נקודת הכניסה.** תוסף ווידג'ט חייב להתחיל ב-`_NSExtensionMain`, כמו ש-Xcode מקשר אותו. בנייה ב-SwiftPM יוצרת `main` רגיל. התוסף רץ, אבל לא מתחבר למערכת התוספים. ה-Package מגדיר את זה בדגלי הקישור של יעד הווידג'ט.
2. **החתימה.** macOS מתעלם מווידג'טים של אפליקציה עם חתימה מקומית בלבד (ad-hoc).

## מבנה

- `Sources/MyZmanMac/Model`: מודל וחישובים. משותף לווידג'ט דרך קישורים סימבוליים ב-`Sources/MyZmanWidget`.
- `Sources/MyZmanMac/Data`: הקטלוג והמיקומים, נוצרו מקבצי MyZman.
- `Sources/MyZmanMac/Services`: תזכורות, יומן, מיקום, ייצוא.
- `Sources/MyZmanMac/Views`: חלונית והגדרות.

- **דף יומי** מחושב בקוד שלנו (`DafYomi.swift`), כי החישוב של KosherSwift 2.0.0 שגוי וקורס סמוך לסוף מחזור.
